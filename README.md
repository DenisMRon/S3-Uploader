# S3-Uploader
Задание на вакансию в компанию Базис-Центр

Тестовое задание на разработку приложения для многопоточной загрузки файлов в S3 совместимое хранилище
1. Наименование и область применения
Название программы: «S3 MultiUploader»
Область применения: приложение предназначено для многопоточной загрузки файлов любого размера в S3 совместимые хранилища с графическим интерфейсом пользователя.
Целевая аудитория: системные администраторы, инженеры, пользователи, работающие с большими объёмами данных.
Объект использования: рабочие станции под управлением Windows и Linux.
2. Назначение разработки
Функциональное назначение:
•	многопоточная загрузка файлов в S3 совместимые хранилища;
•	мониторинг прогресса загрузки в реальном времени;
•	управление настройками подключения к хранилищу.
Эксплуатационное назначение: обеспечение удобного и быстрого способа передачи данных в облачные хранилища пользователями без глубоких технических знаний.
3. Технические требования к программе
3.1. Требования к функциональности
Приложение должно обеспечивать:
•	добавление файлов и папок для загрузки (перетаскивание, выбор через диалог);
•	настройку параметров подключения к S3 хранилищу (endpoint, access key, secret key, bucket);
•	выбор региона хранилища (если требуется);
•	установку количества потоков для параллельной загрузки (настраиваемый параметр, по умолчанию 5);
•	отображение прогресса загрузки для каждого файла (в процентах и в виде полосы прогресса);
•	уведомления о завершении операций;
•	отмену текущей операции загрузки.


3.2. Требования к интерфейсу
Графический интерфейс должен содержать:
•	главное окно с вкладками «Загрузка», «Настройки»;
•	панель добавления файлов/папок (кнопка «Добавить файлы», «Добавить папку», поддержка drag and drop);
•	таблицу загружаемых файлов с колонками: «Имя», «Размер», «Прогресс», «Статус», «Скорость»;
•	индикатор общего прогресса загрузки;
•	панель настроек подключения (поля для ввода endpoint, access key, secret key, выбора bucket и региона);
•	вкладку «История» с таблицей: «Дата», «Файл», «Размер», «Статус», «Время загрузки»;
•	строку состояния с информацией о текущей скорости, общем количестве файлов, статусе соединения.
3.3. Требования к надёжности
•	обработка сетевых ошибок и повторные попытки (настраиваемое количество, по умолчанию 3);
•	сохранение настроек приложения между запусками.
3.4. Требования к совместимости
•	Язык программирования: Delphi (версия 12.0 или новее).
•	Поддерживаемые ОС: Windows 10/11 (64 bit), Linux (Ubuntu 20.04 LTS и новее).
•	S3 совместимые хранилища: AWS S3, MinIO, Ceph RGW, DigitalOcean Spaces и аналогичные.
•	Библиотеки: Indy 10 (для HTTP запросов), Synapse (альтернатива), AWS SDK для Delphi (если доступно) или прямая работа с REST API S3.
3.5. Требования к производительности
•	скорость загрузки — максимально возможная, ограниченная только пропускной способностью сети и возможностями хранилища;
•	использование до 10 параллельных потоков (настраивается пользователем).
